# Code of Conduct

PitchTrace contributors are expected to communicate respectfully, welcome good-faith questions, give actionable technical feedback, and avoid harassment, discrimination, threats, or publication of private information.

Project maintainers may edit or remove abusive content and may temporarily or permanently restrict participation when behavior threatens people or the project. Security disclosures must follow `SECURITY.md`.

Report conduct concerns through an appropriate private GitHub channel. Do not publish sensitive personal details in an issue.
